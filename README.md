# Declutter Dice

One roll. One tiny task. One less thing to carry.

A mobile-first web app prototype: roll a die for a tiny digital decluttering
task, complete it, and build a streak. 72 tasks across 6 categories, XP and
level system, all state stored locally on-device (no backend).

## Run it locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Status

Currently a browser-based prototype (single HTML/CSS/JS file). Packaging
into a real Android/iOS app (Capacitor) and store submission is tracked
separately.
